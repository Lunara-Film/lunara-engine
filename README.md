# lunara-engine

Standalone Streamlit recommendation application with CSV data and TMDB calls.
It is separate from the current Lunara WordPress Theme and plugins; its hosting
relationship is not established by this repository's contributor policy.

Read [AGENTS.md](AGENTS.md) for agent merge authority. Agents handle verified,
in-scope PR merges without a routine manual merge step for Dalton. There is no
checked-in CI workflow; record relevant local validation for each change.
Runtime deployment remains separately authorized.
